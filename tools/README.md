# 工具集说明

这个目录包含用于股票信息下载器的通用工具，这些工具可以帮助进行内容验证、页面监控和其他辅助功能。

## 🛠️ 可用工具

### 1. 内容真实性验证工具 (content_validator.py)

用于验证网页翻页后内容是否真正更新，确保分页功能正常工作。

**使用方法:**
```bash
python tools/content_validator.py --stock-code 300470 --org-id 9900023856 --max-pages 3
```

**参数说明:**
- `--stock-code`: 股票代码 (必填)
- `--org-id`: 组织ID (必填)
- `--max-pages`: 最大验证页数 (默认: 3)
- `--headless`: 无头模式
- `--no-report`: 不保存报告
- `--timeout`: 超时时间 (默认: 30秒)

**输出示例:**
```
=== 内容真实性验证报告 ===
股票代码: 300470
验证时间: 2025-09-11 20:30:45
验证页数: 3
整体状态: healthy

📊 页面分析结果:
  第1页: 30个文档, 日期范围: 2025-2024
  第2页: 30个文档, 日期范围: 2024-2023
  第3页: 30个文档, 日期范围: 2023-2022

🔍 内容差异分析:
  1 vs 2: ✅ 不同
  2 vs 3: ✅ 不同

💡 建议:
  - ✅ 分页功能正常 - 各页内容有差异
```

### 2. 页面监控工具 (page_monitor.py)

用于持续监控网页每页的所有文档内容，提供详细的文档列表和跨页面对比分析。

**使用方法:**
```bash
python tools/page_monitor.py --stock-code 300470 --org-id 9900023856 --max-pages 5 --export-format json
```

**参数说明:**
- `--stock-code`: 股票代码 (必填)
- `--org-id`: 组织ID (必填)
- `--max-pages`: 最大监控页数 (默认: 5)
- `--headless`: 无头模式
- `--no-save`: 不保存结果
- `--export-format`: 导出格式 (json/csv, 默认: json)
- `--timeout`: 超时时间 (默认: 30秒)

**输出特点:**
- 显示每页的所有文档详细列表
- 按日期排序显示文档
- 分析每页的日期分布
- 跨页面内容对比分析
- 生成详细的监控报告

## 📊 工具对比

| 工具 | 主要用途 | 输出详细程度 | 保存格式 | 适用场景 |
|------|----------|--------------|----------|----------|
| content_validator.py | 快速验证分页功能是否正常 | 中等 | JSON | 日常验证、故障排查 |
| page_monitor.py | 详细监控所有页面内容 | 高 | JSON/CSV | 深度分析、问题诊断 |

## 🔧 技术特点

### 共同特性
- ✅ **Chrome稳定性**: 使用2024-2025年最新解决方案，避免tab crash
- ✅ **智能等待**: AJAX内容加载等待机制
- ✅ **错误恢复**: 完善的错误处理和重试机制
- ✅ **详细日志**: 完整的操作日志记录
- ✅ **报告导出**: 支持结果保存和导出

### 内容验证原理
两个工具都基于以下原理验证分页功能：
1. **内容差异性**: 比较相邻页面的文档标题和内容
2. **日期分布**: 分析各页文档的日期范围变化
3. **数量变化**: 监控每页文档数量的合理性
4. **导航验证**: 确认页面跳转是否成功

## 📁 输出文件

工具运行后会生成以下文件：

### 内容验证工具
- `content_validation_report_{股票代码}_{时间戳}.json` - 验证结果报告

### 页面监控工具  
- `page_monitor_{股票代码}_{时间戳}.json` - 详细监控数据
- `page_monitor_{股票代码}_{时间戳}.csv` - CSV格式导出（如选择）

## 🎯 使用建议

1. **日常验证**: 使用 `content_validator.py` 快速检查分页功能
2. **问题诊断**: 使用 `page_monitor.py` 进行详细分析
3. **自动化测试**: 可将这些工具集成到CI/CD流程中
4. **故障排查**: 当下载功能异常时，先用这些工具验证网站状态

## 🔍 验证成功标准

- ✅ **内容差异**: 相邻页面文档内容不同
- ✅ **日期变化**: 各页日期范围有明显变化
- ✅ **导航成功**: 能够成功跳转到指定页面
- ✅ **加载完成**: 页面内容完全加载

如果验证发现异常，工具会提供具体的诊断建议。
